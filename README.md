# Data C100 Project A1: Exploring Cook County Housing

A notebook involving reflections on the granularity of a dataset containing over 500,000 property sale records from Cook County, Illinois, exploratory data analysis and visualizations using Pandas and Seaborn, and more. All done for a Data C100: Principles and Techniques of Data Science project!
